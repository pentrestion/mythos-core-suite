# Mythos Core Suite

A curated collection of custom security and engineering skill files designed to accelerate AI-assisted research, threat-informed analysis, Proof-of-Concept generation, secure patching, and architecture planning.

## Why this repository exists

Mythos Core Suite packages a set of reusable AI skill definitions for security-focused workflows, including:

- ethical security research and vulnerability analysis
- PoC generation and execution guidance
- dependency isolation for safe testing environments
- threat-framework mapping and risk prioritization
- secure software architecture and system design

This repository is optimized for teams and researchers using AI-assisted tooling to improve operational consistency, reduce friction, and standardize structured security workflows.

## Skill summaries

### `mythos.md`

The core operational doctrine for a security-focused AI persona. It establishes structured investigation logic, verification-first practices, and a red-team mindset for assessing systems. This file is the “brain” of the repository and defines how the system should reason about targets, evidence, and exploitation chains.

### `dependency-manager.md`

This file focuses on securely resolving and managing project dependencies in isolated execution environments. It helps reduce environment conflicts and supports safe reproduction of security testing workflows without polluting the host system.

### `poc.md`

A practical workflow for generating a working proof-of-concept from a vulnerability statement. It emphasizes building context first, then creating a standalone reproduction script, and validating the finding before escalating or fixing it.

### `security-patcher.md`

This document provides a security remediation process that begins with context gathering, validates the vulnerability, patches the issue, and then re-tests the fix to confirm the result. It is meant to align remediation with evidence-based engineering.

### `senior-architect.md`

A blueprint for senior-level system design, focused on production-ready backend architecture, modular structure, secure patterns, and fast-moving implementation standards. It helps transform an AI assistant into a more disciplined full-stack engineering partner.

### `sec-frameworks-2026.md`

This skill maps modern security operations concepts to the most relevant frameworks of 2026, including MITRE ATT&CK, MITRE ATLAS, CTEM, and NIST CSF 2.0. It is designed for teams that need threat-informed defense, AI safety analysis, and strategic risk prioritization.
